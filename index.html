The number hidden in the stripes

Every barcode is a number drawn as 95 black-or-white slots. A scanner reads the slots, turns them back into digits, then checks the last digit to decide whether to trust what it saw.

Why it works

Widths, not shades. Each digit is a pattern of 7 slots, for example 3 is 0111101. Because the scanner measures stripe widths, it doesn’t matter how fast you swipe.

Two alphabets. The right half uses the exact opposite colours of the left half. That is how a scanner knows which way up the code is: flip the barcode and the left side stops matching, so it reads backwards instead.

Two safety nets. Every left digit has an odd number of black slots (right digits, an even number), so one flipped slot never makes a valid digit. And the last digit makes the weighted sum a multiple of 10, so one wrong digit is always caught. Damage must hit two or more digits and line up by luck to get through.

Why 3 and 1? Weighting every other digit differently means swapping two neighbours usually changes the sum, so the swap is caught. Try the Typo lab above.

Simplified: this is UPC-A, the 12-digit code on US products. The scanner here sees a perfect row of slots, with no blur or tilt. The encoder, decoder, check digit and the test above all run in this page’s own code, with no libraries and no network.

Questions you didn’t ask

Does the barcode contain the price?

No. It only holds an ID number. The shop’s computer looks the number up and finds the product and its price, which is why a shop can change a price without printing new barcodes.

Why exactly 95 slots?

3 for the start guard, 42 for six left digits, 5 for the middle guard, 42 for six right digits and 3 for the end guard: 3 + 42 + 5 + 42 + 3 = 95.

How does a scanner “see” black and white?

It shines light across the code and measures how much bounces back. Black slots soak up light and white slots reflect it, so the scanner gets a signal that goes low and high. How long it stays low or high is the width of a stripe.

Why do some barcodes have 13 digits?

The 13-digit EAN-13 is used outside North America. A 12-digit UPC-A is the same code with a 0 in front, so an EAN-13 scanner can read it.
